AUTHORSHIP RECORD — AEVUM (FILE PROTOCOL)
========================================================================

THE WORK
------------------------------------------------------------------------
aevum — a file protocol for running permanent projects with disposable
agents. The instance is mortal; the project is not. The protocol
externalizes continuity into written artifacts: the baton (serial
testimony that looks backward), the table (the append-only board where
parallel instances coordinate), the lineage (the genealogy across
generations), and a compare-and-swap that refuses the silent overwrite.
